# Лабораторная работа 4. Строки на ассемблере

## Что делает программа
Две программы, работающие со строками через ассемблер:

1. `1.cpp` + `string_ops.asm` — программа ищет в строке, разделённой заданным символом-разделителем, слова-палиндромы, копирует их и сортирует по длине. Проверка «слово является палиндромом» (`asm_is_palindrome`) и копирование слова (`asm_copy_palindrome`) реализованы в **отдельном ассемблерном модуле** `string_ops.asm` (MASM, x64), C++-код вызывает их через `extern "C"`.

2. `2.cpp` — аналоги стандартных функций работы со строками, написанные на вложенном ассемблере:
   - `asm_strcmp` — сравнение строк;
   - `asm_strcpy` — копирование строки;
   - `asm_strchr` — поиск символа в строке;
   - `asm_replace_char` — замена всех вхождений символа.
   Программа демонстрирует каждую функцию на тестовых строках.

## Файлы
- `1.cpp` — поиск и сортировка палиндромов.
- `string_ops.asm` — ассемблерный модуль (x64, MASM): проверка палиндрома и копирование.
- `2.cpp` — ассемблерные аналоги strcmp/strcpy/strchr/замены символа.
- `lab_04_Gorbatovsky.rar` — архив с исходниками.

## Сборка и запуск
- `1.cpp` собирается вместе с `string_ops.asm` в Visual Studio (проект должен включать ассемблерные файлы, платформа x64).
- `2.cpp` — обычный консольный проект MSVC в режиме x86 (вложенный ассемблер).
