# Лабораторная работа 1. Вычисление выражений на встроенном ассемблере

## Что делает программа
Две программы на C++ с вложенным ассемблером x86 (MSVC, 32-битный режим):

1. `lab_01_1.cpp` — вычисление целочисленного выражения
   `Y = (25/b³ + 4ac + ax³/2) / (3x² − b/(7a) − 6)`
   целиком командами ассемблера (`imul`, `idiv`, `cdq`), с проверкой деления на ноль и нулевых коэффициентов через исключения.

2. `lab_01_2.cpp` — вычисление выражения с плавающей точкой
   `x·ln(x) + y/(cos(x) − x/3)`
   с использованием команд сопроцессора FPU (`fyl2x`, `fldln2`, `fcos`, `fdiv` и т.д.).

## Файлы
- `lab_01_1.cpp` — целочисленное выражение на ассемблере.
- `lab_01_2.cpp` — выражение на FPU.
- `lab_01.zip` — архив с исходниками.

## Сборка и запуск
Компилировать в Visual Studio (MSVC) в режиме x86 (вложенный ассемблер не поддерживается в x64). Программы запрашивают исходные числа с клавиатуры и выводят результат.
