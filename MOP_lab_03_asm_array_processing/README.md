# Лабораторная работа 3. Обработка массивов на встроенном ассемблере

## Что делает программа
Три программы на C++, где обработка массива выполняется на ассемблере x86:

1. `1.cpp` — поиск первого максимального и последнего минимального элементов массива и обмен их местами (адресация `[esi + edx*4]`, циклы на `loop`).
2. `2.cpp` — подсчёт количества локальных минимумов и локальных максимумов массива (сравнение элемента с соседями).
3. `3.cpp` — поиск пересечения двух отсортированных по возрастанию массивов методом двух указателей (слияние); результат — общие элементы без повторов.

## Файлы
- `1.cpp` — обмен max/min.
- `2.cpp` — локальные минимумы и максимумы.
- `3.cpp` — пересечение отсортированных массивов.
- `lab_03.rar` — архив с исходниками.

## Сборка и запуск
Компилировать в Visual Studio (MSVC) в режиме x86. Программы запрашивают размер и элементы массивов с клавиатуры и выводят результат.
