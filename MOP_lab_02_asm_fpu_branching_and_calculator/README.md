# Лабораторная работа 2. Условные переходы и калькулятор на ассемблере (FPU)

## Что делает программа
Две программы на C++ с вложенным ассемблером x86:

1. `1.cpp` — вычисление кусочно-заданной функции с помощью условных переходов по результату сравнения команд FPU (`fldz`, `fcom`, `fstsw ax`, `sahf`):
   - `x < 0` → `x + 4`
   - `0 ≤ x < 1` → `x + 1`
   - `1 ≤ x ≤ 2` → `2`
   - `x > 2` → `3x − 4`

2. `2.cpp` — калькулятор двух вещественных чисел: пользователь вводит числа и знак операции (`+`, `-`, `*`, `/`); выбор операции и само вычисление выполняются на ассемблере через команды FPU, с проверкой деления на ноль.

## Файлы
- `1.cpp` — кусочно-заданная функция.
- `2.cpp` — калькулятор на FPU.


## Сборка и запуск
Компилировать в Visual Studio (MSVC) в режиме x86. Программы запрашивают данные с клавиатуры и выводят результат.
